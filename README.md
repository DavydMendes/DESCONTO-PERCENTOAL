🛒 Sistema de Desconto Progressivo
📌 Objetivo do projeto


O sistema calcula o desconto de uma compra de acordo com o valor total informado pelo usuário. Quanto maior o valor da compra, maior será o percentual de desconto aplicado.

💻 Linguagem utilizada
🐍 Python
🐙 GitHub
📊 Regras de desconto

O sistema utiliza as seguintes regras:

Valor da compra	Desconto
Menor que R$ 200,00	5%
De R$ 200,00 até menor que R$ 300,00	10%
R$ 300,00 ou mais	15%
🧮 Fórmula utilizada

O valor do desconto é calculado pela fórmula:

Valor do desconto = Valor da compra × Percentual de desconto ÷ 100

Depois, o valor final é calculado:

Valor final = Valor da compra - Valor do desconto
▶️ Como executar o programa
Instale o Python no computador.
Abra a pasta do projeto no Visual Studio Code.
Abra o arquivo sistema_desconto.py.
Execute o programa pelo VS Code ou pelo terminal.
Digite o valor total da compra quando solicitado.
O programa mostrará:
Valor da compra;
Percentual de desconto;
Valor do desconto;
Valor final a pagar.
Exemplo
Digite o valor total da compra: R$ 350

--- RESUMO DA COMPRA ---
Valor da compra: R$ 350.00
Desconto aplicado: 15%
Valor do desconto: R$ 52.50
Valor final a pagar: R$ 297.50
